# 🔐 ربات تلگرام فروش اشتراک (پرداخت و تحویل خودکار)

ربات تلگرامی کامل برای فروش اشتراک/سرویس، با **پرداخت، تایید و تحویل کاملاً خودکار**.

## ✨ امکانات
- فروش پلن‌ها با دسته‌بندی، حجم و مدت دلخواه
- اتصال مستقیم به پنل **Pasarguard** و ساخت خودکار سرویس بعد از پرداخت
- کیف پول و شارژ حساب
- **تایید خودکار پرداخت** با خواندن پیامک واریز بانک (وب‌هوک پیامک؛ بلو، ملی، تجارت و ...)
- اکانت تست رایگان
- سیستم **همکار / نماینده فروش** با پلن‌ها و قیمت اختصاصی
- سیستم دعوت دوستان و مسابقه (تورنومنت) دعوت
- عضویت اجباری در کانال
- اعلان‌ها و یادآوری انقضا (زمان‌بندی خودکار)
- پنل مدیریت کامل داخل ربات: کاربران، پلن‌ها، کانفیگ‌ها، ادمین‌ها با سطح دسترسی، پیام همگانی، تیکت پشتیبانی، ویرایش متن‌ها و دکمه‌ها

## 🧰 تکنولوژی
Python · aiogram 3 · SQLite · aiohttp (webhook) · pasarguard SDK

## 🚀 راه‌اندازی
```bash
pip install -r requirements.txt
cp .env.example .env      # مقادیر را پر کنید
python -m vpn_bot
```
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (با کاما جدا) |
| `WEBHOOK_HOST` / `WEBHOOK_PORT` | دامنه و پورت وب‌هوک |

دیتابیس در اولین اجرا به‌صورت خودکار و خالی ساخته می‌شود.
